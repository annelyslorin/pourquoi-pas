# Pourquoi pas ?

Site de side quests en HTML et CSS, réalisé pour Le Wagon.

## Modifier les textes

- `index.html` : textes de la page d’accueil.
- `chez-toi-tranquille.html` : les cinq quêtes tranquilles.
- `chez-toi-creatif.html` : les cinq quêtes créatives.
- `dehors-decouverte.html` : les cinq quêtes de découverte.
- `dehors-rencontres.html` : les cinq quêtes de rencontres.

Ouvrir un fichier, cliquer sur le crayon, modifier uniquement les textes entre les balises HTML, puis cliquer sur **Commit changes**.

Le design se trouve dans `css/style.css` et `css/components/`.

Le questionnaire Typeform reste à créer et à intégrer. Le choix direct du profil fonctionne déjà.
